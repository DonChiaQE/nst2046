# AI-use log

Course requirement (NST2046 guidelines §7): log every AI use that materially shaped method or
conclusions, with what was used or rejected and how it was verified. Routine edits are not logged.
Two distinct roles for Claude in this project, kept separate:

- **Claude as tool** — Claude Code (Opus 5 / Sonnet 5, via the Claude desktop app) writing code,
  running literature searches, reading sources, drafting documents, under our direction.
- **Claude as object of study** — the Claude API as the LLM extractor and judge in the experiment.
  Not used yet (phase 3); every call will be logged here with model, version and prompt.

Verification standard: code is verified by tests and by inspection; factual claims by reading the
primary source ourselves; literature summaries by cross-checking independent readings against the
PDF text. Nothing an AI produced is cited as evidence for a factual claim.
