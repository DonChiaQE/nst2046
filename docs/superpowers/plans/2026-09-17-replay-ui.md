# Replay UI (Phase 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A FastAPI app and a vanilla-JS page that replay any tower recording through the phase-1 conflict engine — runway board, transmission feed with parsed events, conflict banners, per-transmission audio — started with `uvicorn atcdb.api:app`.

**Architecture:** `atcdb/replay.py` gains the lookups the API needs (`get_recording`, transcript-model pinning) and a concurrency-safe cache insert. A new pure module `atcdb/serialize.py` defines every JSON shape. `atcdb/api.py` is routing only: it validates query parameters, opens one SQLite connection per request inside each handler, and serves `atcdb/static/` at `/`. The page fetches one recording's whole timeline and scrubs through it locally.

**Tech Stack:** Python 3.14, FastAPI 0.141.1, Uvicorn 0.53.0, httpx2 2.13.0 (Starlette test client), sqlite3, pytest; plain HTML/CSS/JS with no build step.

**Spec:** `docs/superpowers/specs/2026-09-12-conflict-engine-design.md` — Section 3 and its **Section 3 addendum** (the addendum wins where they differ). This plan is phase 2 of the spec's build order. Phase 1 is merged (see `docs/superpowers/plans/2026-09-15-conflict-engine-core.md`, including its "Phase-1 review carry-overs" section, which this plan resolves for the API surface).

## Global Constraints

- New dependencies, pinned exactly, and no others: `fastapi==0.141.1`, `httpx2==2.13.0`, `uvicorn==0.53.0`. No `python-multipart` (phase 4), no `anthropic` (phase 3), no npm, no bundler.
- `atcdb/serialize.py` is pure: it imports only `atcdb.engine`, `atcdb.parsing` and `atcdb.replay`; no FastAPI, no sqlite3.
- `atcdb/api.py` is routing only. Each handler opens and closes its own connection with `closing(init_db(db_path))`. No yield-dependency for the connection, no shared connection, no `check_same_thread` flag.
- Endpoints, exactly: `GET /api/capabilities`, `GET /api/recordings`, `GET /api/recordings/{recording_id}/replay`, `GET /api/clips/{transmission_id}`; the static front-end is mounted at `/` after the API routes; OpenAPI docs at `/api/docs`.
- Errors: an unknown recording id → 404; a known recording with no transcripts of the requested kind → 200 with `steps: []`; an unknown parser, context mode or transcript kind → 422 with a `detail` string containing "unknown"; a missing clip file, an unknown transmission, or a clip path escaping the project root → 404.
- Replayable transcript kinds: `TRANSCRIPT_KINDS = ("gold", "asr")`. Context modes come from `atcdb.parsing.CONTEXT_MODES`; parsers from `atcdb.replay.PARSERS`.
- Transcript pinning: when no `transcript_model` is given, gold replays use `human`; any other kind uses its alphabetically first model. An explicit `transcript_model` query parameter overrides.
- The `events` cache key and `parse_rules.VERSION` (`"v1"`) are unchanged.
- Front-end: exactly three files in `atcdb/static/` (`index.html`, `app.js`, `style.css`); play advances every 2000 ms; ArrowLeft/ArrowRight step; the page never scrolls on desktop (board column and feed scroll independently) and has no horizontal overflow at 420 px wide; light and dark themes via `prefers-color-scheme`.
- Tests follow the repo's style: plain pytest functions, real SQLite files under `tmp_path`, FastAPI's `TestClient` for HTTP, no mock framework. Run with `.venv/bin/python -m pytest`.
- Commit after every task; `feat:`/`test:`/`docs:` subjects ending with the attribution lines the session provides.

Domain vocabulary for the engineer: a **recording** is one continuous ATC audio capture; a **transmission** is one radio call in it, with one or more **transcripts** (`gold` = human-written, `asr` = Whisper output). The phase-1 engine folds parsed **events** (LAND, TAKEOFF, LUAW = line up and wait, CROSS, HOLD_SHORT, HANDOFF, READBACK, ...) into a **state**: runway **reservations** plus per-aircraft status. A **conflict** is RUNWAY (incompatible reservations) or READBACK (pilot did not read back an item), severity `alert` or `warning`. A **timeline** is one `Step` per transmission: its events, the conflicts they raised, and the state after it.

```python
def list_recordings(conn: sqlite3.Connection, facility: str = "Tower", min_transmissions: int = 4,
                    transcript_kind: str = "gold") -> list[dict]:
    """Recordings worth replaying: the given facility, enough transmissions, at least one runway mention."""
    rows = conn.execute(
        """SELECT r.id, s.name AS source, r.external_id, r.airport_icao, r.facility,
                  COUNT(DISTINCT x.id) AS n_transmissions,
                  COUNT(DISTINCT CASE WHEN t.normalized_text LIKE '%runway%' THEN x.id END) AS n_runway_mentions
           FROM recordings r
           JOIN sources s ON s.id = r.source_id
           JOIN transmissions x ON x.recording_id = r.id
           JOIN transcripts t ON t.transmission_id = x.id AND t.kind = ?
           WHERE r.facility = ?
           GROUP BY r.id
           HAVING n_transmissions >= ? AND n_runway_mentions >= 1
           ORDER BY n_transmissions DESC, r.id""", (transcript_kind, facility, min_transmissions)).fetchall()
    return [dict(r) for r in rows]


def get_recording(conn: sqlite3.Connection, recording_id: int) -> dict | None:
    """One recording's identity (id, source, external_id, airport_icao, facility), or None if the id is unknown.
    Distinguishes "no such recording" from "a recording with no transcripts of the requested kind"."""
    row = conn.execute(
        """SELECT r.id, s.name AS source, r.external_id, r.airport_icao, r.facility
           FROM recordings r JOIN sources s ON s.id = r.source_id
           WHERE r.id = ?""", (recording_id,)).fetchone()
    return dict(row) if row else None


def transcript_models(conn: sqlite3.Connection) -> dict[str, list[str]]:
    """Transcript kinds present in the DB, each with its models in alphabetical order."""
    out: dict[str, list[str]] = {}
    for r in conn.execute("SELECT DISTINCT kind, model FROM transcripts ORDER BY kind, model"):
        out.setdefault(r["kind"], []).append(r["model"])
    return out


def default_transcript_model(conn: sqlite3.Connection, transcript_kind: str) -> str | None:
    """The transcript model a replay pins when none is given, so cache keys do not drift between runs: `human` for
    gold (some transmissions also carry an `atco2-xml` gold transcript), otherwise the alphabetically first model.
    None when the DB has no transcripts of that kind."""
    models = transcript_models(conn).get(transcript_kind, [])
    if transcript_kind == "gold" and "human" in models:
        return "human"
    return models[0] if models else None
```

```python
def get_events(conn: sqlite3.Connection, tx: Transmission, parser: str, ctx: Context,
               model: str | None = None, model_version: str | None = None) -> list[Event]:
    """Events for one transcript under (parser, model, version, context mode): from the `events` cache, or parsed
    and stored. A parser exception propagates and nothing is stored, so the next call retries. An empty parse is
    stored as one NOOP row, so the transcript is not a cache miss forever. Rows another request stored first (two web
    requests replaying the same uncached recording) are kept, not an error."""
    if model is None:
        model, model_version = PARSER_MODELS[parser]
    model_version = model_version or ""
    rows = conn.execute(
        """SELECT kind, callsign, runway, extra_json FROM events
           WHERE transcript_id = ? AND parser = ? AND model = ? AND model_version = ? AND context = ?
           ORDER BY seq""", (tx.transcript_id, parser, model, model_version, ctx.mode)).fetchall()
    if rows:
        return [row_to_event(r["kind"], r["callsign"], r["runway"], r["extra_json"], t=tx.start_s, text=tx.text) for r in rows]
    events = PARSERS[parser](tx, ctx) or [NoOp(t=tx.start_s, text=tx.text)]
    try:
        conn.executemany(
            """INSERT OR IGNORE INTO events (transcript_id, parser, model, model_version, context, seq, kind, callsign, runway, extra_json)
               VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?, ?)""",
            [(tx.transcript_id, parser, model, model_version, ctx.mode, i, *event_to_row(e)) for i, e in enumerate(events)])
        conn.commit()
    except Exception:
        conn.rollback()   # a partial insert must never be committed later by someone else's commit
        raise
    return events
```

```python
"""Plain-dict views of replay objects, shaped for the JSON API (spec Section 3 addendum).

Pure: no web framework, no DB. `atcdb/api.py` only routes; every response shape is defined and tested here.
"""
from atcdb.engine import Conflict, Event, State
from atcdb.parsing import KINDS, Transmission
from atcdb.replay import Step, Timeline


def event_dict(e: Event) -> dict:
    """Every event has the same four keys; `runway` is set on runway instructions, `to` on handoffs."""
    return {"kind": KINDS[type(e)], "callsign": e.callsign, "runway": getattr(e, "runway", None), "to": getattr(e, "to", None)}


def conflict_dict(c: Conflict) -> dict:
    return {"type": c.type, "severity": c.severity, "runway": c.runway, "callsigns": list(c.callsigns), "seq": c.seq,
            "explanation": c.explanation}


def transmission_dict(tx: Transmission) -> dict:
    return {"id": tx.id, "transcript_id": tx.transcript_id, "start_s": tx.start_s, "role": tx.role, "text": tx.text}


def board_dict(state: State) -> dict[str, list[dict]]:
    """Active reservations per runway, in the order they were made."""
    return {rwy: [{"callsign": r.callsign, "kind": r.kind} for r in res] for rwy, res in sorted(state.runways.items())}


def aircraft_list(state: State) -> list[dict]:
    """Every aircraft the engine has seen, by callsign."""
    return [{"callsign": a.callsign, "runway": a.runway, "kind": a.kind, "holding_short": a.holding_short, "pending": a.pending}
            for _, a in sorted(state.aircraft.items())]


def step_dict(index: int, step: Step) -> dict:
    return {"index": index, "transmission": transmission_dict(step.tx), "events": [event_dict(e) for e in step.events],
            "conflicts": [conflict_dict(c) for c in step.conflicts], "error": step.error,
            "board": board_dict(step.state), "aircraft": aircraft_list(step.state)}


def runways_named(tl: Timeline) -> list[str]:
    """Every runway any event in the recording names, so the UI can lay out the board once and never reflow."""
    return sorted({e.runway for s in tl.steps for e in s.events if getattr(e, "runway", None)})


def timeline_dict(tl: Timeline, recording: dict, transcript_model: str | None) -> dict:
    return {"recording": recording, "parser": tl.parser, "model": tl.model, "model_version": tl.model_version,
            "context": tl.context, "transcript_kind": tl.transcript_kind, "transcript_model": transcript_model,
            "runways": runways_named(tl), "steps": [step_dict(i, s) for i, s in enumerate(tl.steps)]}
```

  - `index.html` element ids Task 4's script relies on: `recording`, `parser`, `context`, `transcript`, `first`, `prev`, `play`, `next`, `last`, `scrub`, `position`, `banner`, `status`, `board`, `conflicts`, `feed`, `audio`; it loads `style.css` and `app.js` (both created in Task 4 — until then those two requests 404, which is expected).
- Design notes the tests pin:
  - Connections are opened inside each handler, not through a yield-dependency: FastAPI can run a sync dependency and a sync handler on different pool threads, and a sqlite3 connection must not cross threads.
  - The clip route checks containment **lexically** (`os.path.normpath`), not with `resolve()`: it must refuse `../` and absolute clip paths but still serve clips under a symlinked `data/` directory, which is how large datasets are often mounted.
  - The static mount is registered last so `/api/...` routes win.

```python
"""FastAPI app: the replay JSON API plus the static front-end (spec Section 3 and its addendum).

Routing only: response shapes live in atcdb/serialize.py, replay logic in atcdb/replay.py. Each handler opens and
closes its own SQLite connection, because FastAPI may run a sync dependency and a sync handler on different pool
threads and a connection must not cross threads. `uvicorn atcdb.api:app` serves the corpus DB; tests build their own
app with `create_app(db_path, project_root)`.
"""
import os
from contextlib import closing
from pathlib import Path

from fastapi import FastAPI, HTTPException, Query
from fastapi.responses import FileResponse
from fastapi.staticfiles import StaticFiles

from atcdb.parsing import CONTEXT_MODES
from atcdb.replay import (PARSER_MODELS, PARSERS, build_timeline, default_transcript_model, get_recording,
                          list_recordings, transcript_models)
from atcdb.schema import init_db
from atcdb.serialize import timeline_dict

ROOT = Path(__file__).resolve().parents[1]
STATIC_DIR = Path(__file__).resolve().parent / "static"
TRANSCRIPT_KINDS = ("gold", "asr")   # the kinds a replay can use


def _require(name: str, value: str, allowed) -> None:
    if value not in allowed:
        raise HTTPException(422, f"unknown {name} {value!r}; expected one of {sorted(allowed)}")


def create_app(db_path: Path | str = ROOT / "data/atc.sqlite", project_root: Path | str = ROOT) -> FastAPI:
    root = Path(project_root).absolute()
    app = FastAPI(title="ATC conflict engine", docs_url="/api/docs", redoc_url=None, openapi_url="/api/openapi.json")

    def db():
        return closing(init_db(db_path))

    @app.get("/api/capabilities")
    def capabilities():
        with db() as conn:
            models = transcript_models(conn)
        return {"parsers": [{"name": p, "model": m, "model_version": v} for p, (m, v) in sorted(PARSER_MODELS.items())],
                "contexts": list(CONTEXT_MODES),
                "transcripts": {k: models[k] for k in TRANSCRIPT_KINDS if k in models},
                "live": False}

    @app.get("/api/recordings")
    def recordings(facility: str = "Tower", min_transmissions: int = Query(4, ge=1), transcript: str = "gold"):
        _require("transcript kind", transcript, TRANSCRIPT_KINDS)
        with db() as conn:
            return list_recordings(conn, facility=facility, min_transmissions=min_transmissions, transcript_kind=transcript)

    @app.get("/api/recordings/{recording_id}/replay")
    def replay(recording_id: int, parser: str = "rule", context: str = "window", transcript: str = "gold",
               transcript_model: str | None = None):
        _require("parser", parser, PARSERS)
        _require("context mode", context, CONTEXT_MODES)
        _require("transcript kind", transcript, TRANSCRIPT_KINDS)
        with db() as conn:
            recording = get_recording(conn, recording_id)
            if recording is None:
                raise HTTPException(404, f"no recording {recording_id}")
            model = transcript_model or default_transcript_model(conn, transcript)
            tl = build_timeline(conn, recording_id, parser=parser, transcript_kind=transcript, context=context,
                                transcript_model=model)
        return timeline_dict(tl, recording, model)

    @app.get("/api/clips/{transmission_id}")
    def clip(transmission_id: int):
        with db() as conn:
            row = conn.execute("SELECT clip_path FROM transmissions WHERE id = ?", (transmission_id,)).fetchone()
        # lexical containment check: refuses "../" and absolute clip paths but, unlike resolve(), allows a symlinked data/
        path = Path(os.path.normpath(root / row["clip_path"])) if row and row["clip_path"] else None
        if path is None or not path.is_relative_to(root) or not path.is_file():
            raise HTTPException(404, f"no clip for transmission {transmission_id}")
        return FileResponse(path, media_type="audio/wav")

    app.mount("/", StaticFiles(directory=STATIC_DIR, html=True), name="static")   # last: API routes take precedence
    return app


app = create_app()
```

```javascript
"use strict";
// Replay UI. Loads one recording's whole timeline, then scrubs through it locally; every decision about events and
// conflicts was made server-side, so this file only renders. Served by atcdb/api.py.

const PLAY_MS = 2000;
const ROLE = { controller: "CTL", pilot: "PLT", mixed: "MIX", unknown: "???" };
const $ = (id) => document.getElementById(id);
const ui = { timeline: null, k: 0, timer: null, wanted: new URLSearchParams(location.search).get("recording") };

function el(tag, className, text) {
  const node = document.createElement(tag);
  if (className) node.className = className;
  if (text !== undefined) node.textContent = text;
  return node;
}

function option(value, label) {
  const o = el("option", null, label);
  o.value = value;
  return o;
}

function mmss(seconds) {
  const t = Math.floor(seconds);
  return `${String(Math.floor(t / 60)).padStart(2, "0")}:${String(t % 60).padStart(2, "0")}`;
}

function setStatus(text) {
  $("status").textContent = text;
}

async function getJSON(url) {
  const response = await fetch(url);
  if (!response.ok) {
    const body = await response.json().catch(() => ({}));
    throw new Error(`${response.status} ${body.detail || response.statusText}`);
  }
  return response.json();
}

async function init() {
  const caps = await getJSON("/api/capabilities");
  for (const p of caps.parsers) $("parser").append(option(p.name, `${p.name} (${p.model} ${p.model_version})`));
  for (const c of caps.contexts) $("context").append(option(c, c));
  for (const kind of Object.keys(caps.transcripts)) $("transcript").append(option(kind, kind));
  $("context").value = "window";
  $("transcript").value = "gold";

  $("recording").addEventListener("change", loadReplay);
  $("parser").addEventListener("change", loadReplay);
  $("context").addEventListener("change", loadReplay);
  $("transcript").addEventListener("change", loadRecordings);
  $("first").addEventListener("click", () => jump(0));
  $("prev").addEventListener("click", () => jump(ui.k - 1));
  $("next").addEventListener("click", () => jump(ui.k + 1));
  $("last").addEventListener("click", () => jump(Infinity));
  $("play").addEventListener("click", togglePlay);
  $("scrub").addEventListener("input", () => jump(Number($("scrub").value)));
  document.addEventListener("keydown", (event) => {
    if (event.target instanceof Element && event.target.closest("select, input")) return;   // controls keep their arrows
    if (event.key === "ArrowRight") jump(ui.k + 1);
    else if (event.key === "ArrowLeft") jump(ui.k - 1);
    else return;
    event.preventDefault();
  });
  await loadRecordings();
}

async function loadRecordings() {
  const recordings = await getJSON(`/api/recordings?transcript=${encodeURIComponent($("transcript").value)}`);
  const select = $("recording");
  const previous = ui.wanted || select.value;
  ui.wanted = null;
  select.replaceChildren(...recordings.map((r) =>
    option(r.id, `${r.external_id} (${r.n_transmissions} tx)`)));
  if (recordings.some((r) => String(r.id) === previous)) select.value = previous;
  if (!recordings.length) setStatus("No replayable recordings for this transcript kind.");
  await loadReplay();
}

async function loadReplay() {
  stop();
  const id = $("recording").value;
  ui.timeline = null;
  ui.k = 0;
  if (id) {
    const query = new URLSearchParams({ parser: $("parser").value, context: $("context").value, transcript: $("transcript").value });
    setStatus("Loading…");
    try {
      ui.timeline = await getJSON(`/api/recordings/${id}/replay?${query}`);
      setStatus(ui.timeline.steps.length ? "" : "This recording has no transcripts of that kind.");
      history.replaceState(null, "", `?recording=${id}`);
    } catch (error) {
      setStatus(`Could not load the replay: ${error.message}`);
    }
  }
  render();
}

function jump(k) {
  stop();
  go(k);
}

function go(k) {
  const n = ui.timeline ? ui.timeline.steps.length : 0;
  if (!n) return;
  ui.k = Math.max(0, Math.min(n - 1, k));
  render();
}

function togglePlay() {
  if (ui.timer) return stop();
  const last = ui.timeline.steps.length - 1;
  if (ui.k >= last) go(0);
  ui.timer = setInterval(() => (ui.k >= ui.timeline.steps.length - 1 ? stop() : go(ui.k + 1)), PLAY_MS);
  $("play").textContent = "Pause";
}

function stop() {
  clearInterval(ui.timer);
  ui.timer = null;
  $("play").textContent = "Play";
}

function playClip(transmissionId) {
  const audio = $("audio");
  audio.src = `/api/clips/${transmissionId}`;
  audio.play().catch(() => setStatus("No audio clip for that transmission."));
}

function render() {
  const steps = ui.timeline ? ui.timeline.steps : [];
  const n = steps.length;
  $("scrub").max = Math.max(n - 1, 0);
  $("scrub").value = ui.k;
  $("position").textContent = n ? `${ui.k + 1} / ${n}` : "0 / 0";
  for (const id of ["first", "prev", "play", "next", "last", "scrub"]) $(id).disabled = n === 0;
  if (!n) {
    for (const id of ["board", "feed", "conflicts"]) $(id).replaceChildren();
    $("banner").hidden = true;
    return;
  }
  const step = steps[ui.k];
  renderBanner(step);   // before the feed: the banner changes the feed's height, and the feed scrolls to the current step
  renderBoard(ui.timeline.runways, step);
  renderConflicts(steps);
  renderFeed(steps);
}

function worstSeverity(conflicts) {
  const severities = conflicts.map((c) => c.severity);
  return severities.includes("alert") ? "alert" : severities.includes("warning") ? "warning" : "";
}

function renderBoard(runways, step) {
  const cards = runways.map((runway) => {
    const card = el("div", `card ${worstSeverity(step.conflicts.filter((c) => c.runway === runway))}`.trim());
    card.append(el("h3", null, `Runway ${runway}`));
    const list = el("ul");
    for (const r of step.board[runway] || []) {
      list.append(el("li", `res ${r.kind.toLowerCase()}`, `${r.callsign || "unidentified"} · ${r.kind}`));
    }
    for (const a of step.aircraft.filter((a) => a.holding_short === runway)) {
      list.append(el("li", "hold", `${a.callsign} · holding short`));
    }
    if (!list.children.length) list.append(el("li", "idle", "clear"));
    card.append(list);
    return card;
  });
  $("board").replaceChildren(...cards);
  if (!cards.length) $("board").append(el("p", "idle", "No runway is named in this recording."));
}

function eventLabel(e) {
  return [e.kind, e.callsign || "?", e.runway || e.to || ""].join(" ").trim();
}

function renderFeed(steps) {
  const items = steps.slice(0, ui.k + 1).map((s, i) => {
    const item = el("li", i === ui.k ? "tx current" : "tx");
    const head = el("div", "tx-head");
    const clip = el("button", "clip", "♪");
    clip.type = "button";
    clip.title = "Play clip";
    clip.addEventListener("click", (event) => {
      event.stopPropagation();
      playClip(s.transmission.id);
    });
    head.append(el("span", "time", mmss(s.transmission.start_s)),
      el("span", `role ${s.transmission.role}`, ROLE[s.transmission.role] || "???"),
      el("span", "text", s.transmission.text), clip);
    item.append(head);
    const chips = el("div", "chips");
    for (const e of s.events) if (e.kind !== "NOOP") chips.append(el("span", `chip ${e.kind.toLowerCase()}`, eventLabel(e)));
    for (const c of s.conflicts) chips.append(el("span", `chip flag ${c.severity}`, `${c.severity} · ${c.type.toLowerCase()}`));
    if (s.error) chips.append(el("span", "chip failed", `parse error: ${s.error}`));
    if (chips.children.length) item.append(chips);
    item.addEventListener("click", () => jump(i));
    return item;
  });
  $("feed").replaceChildren(...items);
  items[items.length - 1].scrollIntoView({ block: "nearest" });
}

function renderConflicts(steps) {
  const items = [];
  steps.slice(0, ui.k + 1).forEach((s, i) => {
    for (const c of s.conflicts) {
      const item = el("li", `conflict ${c.severity}`);
      item.append(el("span", "time", mmss(s.transmission.start_s)), el("span", "sev", c.severity), el("span", null, c.explanation));
      item.addEventListener("click", () => jump(i));
      items.push(item);
    }
  });
  $("conflicts").replaceChildren(...items);
  if (!items.length) $("conflicts").append(el("li", "idle", "None yet."));
}

function renderBanner(step) {
  const banner = $("banner");
  banner.hidden = !step.conflicts.length;
  if (banner.hidden) return;
  banner.className = `banner ${worstSeverity(step.conflicts)}`;
  banner.replaceChildren(...step.conflicts.map((c) => el("p", null, `${c.severity.toUpperCase()} · ${c.type}: ${c.explanation}`)));
}

init().catch((error) => setStatus(`Could not start: ${error.message}`));
```
